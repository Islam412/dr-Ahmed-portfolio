# 🍯 رحيق الجنة (Raheeq Al-Jannah) - Honey Shop

[![Live Demo](https://img.shields.io/badge/Live_Demo-raheeq--al--jannah.vercel.app-gold?style=for-the-badge&logo=vercel&logoColor=white&color=g)](https://raheeq-al-jannah.vercel.app)
[![GitHub repo size](https://img.shields.io/github/repo-size/Islam412/RAHEEQ-AL-JANNAH?style=for-the-badge&logo=github&color=gold)](https://github.com/Islam412/RAHEEQ-AL-JANNAH)

A modern, fully-featured e-commerce web application for a honey shop, built with **React**. The platform allows customers to browse a variety of natural honey products, manage a shopping cart, save items to a wishlist, and complete orders with integrated WhatsApp and email notifications.

## ✨ Key Features

*   **Product Catalog:** Browse a wide range of authentic Egyptian honey (e.g., Black Seed, Sidr, Clover, Thyme) with detailed descriptions, benefits, and usage instructions.
*   **Product Details:** Each product features high-quality images, an option to choose weight (`1kg` or `0.5kg`), dynamic pricing, and a quantity selector.
*   **Shopping Cart:** Add/remove items, update quantities, and view a real-time order summary with fixed shipping costs.
*   **Wishlist (Saved Products):** Save favorite products for later, with the ability to move them directly to the cart.
*   **Order Management:** Users fill out a shipping form to place an order.
*   **Automated Notifications:**
    *   Order details are sent directly to a designated **WhatsApp** number via the Green-API.
    *   A formatted order summary is also sent to a specified **Email** address using EmailJS.
*   **Image Upload:** Customers can upload a payment receipt image, which is hosted via **ImgBB** and included in the order notification.
*   **Fully Responsive:** Optimized for all screen sizes (mobile, tablet, and desktop) with a custom, modern CSS design.
*   **User-Friendly Interface:** Modern UI with smooth animations, a navigation menu, and a clean dark-themed aesthetic.

## 🛠️ Tech Stack

### Frontend
*   **Framework:** [React](https://reactjs.org/) (bootstrapped with Create React App)
*   **Routing:** [React Router DOM](https://reactrouter.com/) (v6)
*   **Styling:** Custom CSS with a responsive, modern design
*   **Icons:** [React Icons](https://react-icons.github.io/react-icons/) (Fa, Gi sets)

### APIs & Integrations
*   **WhatsApp Notifications:** [Green-API](https://green-api.com/) - Sends order summaries automatically to a WhatsApp number.
*   **Email Notifications:** [EmailJS](https://www.emailjs.com/) - Sends formatted order details to an email address.
*   **Image Hosting:** [ImgBB API](https://api.imgbb.com/) - Uploads and hosts payment receipt images.
*   **Deployment & Hosting:** [Vercel](https://vercel.com/)
